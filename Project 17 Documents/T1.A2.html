Privacy-Preserving Personal AI Operating System

Most personal assistants still send calendar, message, and file contents to cloud models. That leak of raw personal data blocks everyday trust. This project builds a local-first personal AI operating system that learns routines and preferences, plans over personal context, executes bounded tool actions, and keeps raw data on device. Scope is a consented simulated-user sandbox, not the team’s private accounts. The objective is a working system in which four methods each solve the same full problem and are compared with one published baseline on one harness. Issues include limited local compute, a fair 30-day benchmark, and privacy tests that do not use real identifiers.

The team will build one shared shell—sandbox, tools, memory with deletion, provenance, and conflict resolution, and a planner-executor with per-tool permissions and rollback—and four models that each complete the whole task by a different method: a retrieval-augmented hierarchical planner; a recurrent or state-space routine and preference model; a contextual-bandit policy for proactive suggestions; and a safety critic for irreversible or privacy-sensitive actions. Tools, data, and tests stay the same; only the method changes. Separately, we will reproduce Saad-Falcon et al. (2026, Table 1): OpenJarvis with Qwen3.5-9B at 87.9% PinchBench accuracy versus 93.5% for the default cloud setup. That reproduced result is the common baseline and is not one of the four models. Data are a team-built 30-day simulated personal-data trace plus public OpenJarvis and PinchBench assets.

Every system is scored on task success, intervention rate, preference regret, deletion compliance, privacy leakage, p95 latency, and cost per user-day, including local and cloud variants. The DATA 298A merit target is that the first model, the retrieval-augmented hierarchical planner, matches or exceeds our reproduced Table 1 agent on the unified 30-day harness, with 100% deletion compliance on requested deletes and zero raw-personal-data export on the local path. 298A deliverables are a deployed prototype, that first model, the reproduced baseline, the unified harness, and the 298B plan. 298B adds the other three models, gated retraining, and a full interface.

The system is intended for students and professionals who need help with mail, calendars, and local files but cannot send that content to a third party. The impact is evidence of which method best raises task quality under explicit privacy, latency, and cost limits.

Keywords: personal AI, on-device agents, privacy-preserving systems, hierarchical planning, preference learning
