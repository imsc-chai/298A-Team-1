### Core Problem Statement
Current personal assistants either hallucinate preferences or leak confidential personal information when executing third-party API actions. Our benchmark evaluates:
1. **Longitudinal Preference Learning:** Adapting to implicit user choices (e.g. meeting windows, preferred notification channels) without explicit fine-tuning.
2. **Multimodal Grounding:** Reconciling schedule and task constraints from unstructured visual artifacts (receipts, tickets, whiteboard photos, invoices).
3. **Bounded Action Execution:** Enforcing security sandboxes where outbound drafts never leak protected PII (medical records, security codes, financial balances).
